# 파도멍

목포 대반동 바닷가(유달유원지)를 본떠 만든, 파라솔 하나 들고 와서 앉아 파도가 오가는 모습과 소리를 함께 보는 곳입니다.
목포대교, 고하도, 해상케이블카, 스카이워크가 보이고, 저녁에는 다리 조명과 해변 미디어아트가 켜집니다.
설치 없이 브라우저에서 열리고, 같은 주소에 들어온 사람들이 서로의 파라솔(밤에는 랜턴)을 봅니다.

## 머물게 하는 장치

| 장치 | 내용 | 서버 필요 |
|---|---|---|

| 정각의 배 | 매 정각, 여객선이 7분 동안 다리 아래를 지나감 | 아니요 |
| 밤 9시 상영 | 21:00~21:10, 해변에 빛으로 그린 고래와 물고기 떼가 지나감. 5분 전부터 예고 | 아니요 |
| 손 흔들기 | 다른 사람을 누르면 빛이 건너가고, 받은 사람 곁에 15초 머묾. 밤에는 "랜턴 불 나누기" | 예 |
| 유리병 편지 | 앉아 있으면 2~5분 뒤 파도가 병을 밀어 옴. 누군가 남긴 한 줄이 들어 있음. 나도 한 줄(80자)을 띄울 수 있음 | 예 |

| 자동 이름 | 들어올 때 "느린 물결", "젖은 모래" 같은 바닷가 이름이 저절로 붙음. ↻ 로 바꾸거나 직접 씀 | 아니요 |
| 숨 고르기 | 파도가 밀려올 때 들이쉬고 빠질 때 내쉬도록, 내 둘레에 고리가 커졌다 작아짐 | 아니요 |
| 모래에 쓰기 | 12자까지 모래에 쓰면 같은 해변 사람들에게 보이고, 파도가 닿으면 지워짐. 물가 가까이 쓸수록 빨리, 만조에는 더 멀리까지 지워짐 | 예 |
| 오늘 숫자 | 화면 위에 "오늘 다녀간 사람 ○명" | 예 |

시각은 모두 한국 시각입니다. 해외에서 접속해도 목포의 시간이 흐릅니다.

## 내 컴퓨터에서 먼저 열어 보기

Node.js 18 이상이 필요합니다.

```bash
npm install
ADMIN_KEY=아무열쇠 npm start
```

브라우저에서 `http://localhost:3000` 을 엽니다. 창을 두 개 열면 서로 보입니다.
주소 끝에 `#fast` 를 붙이면 앉은 뒤 4초 만에 유리병이 와서 시험하기 좋습니다.

## 환경변수

| 이름 | 하는 일 |
|---|---|
| `ADMIN_KEY` | 통계와 병 관리 주소를 여는 열쇠. 정하지 않으면 그 주소들은 닫혀 있음 |
| `DATA_DIR` | 병과 통계를 저장할 폴더 (기본: `data`) |
| `METAMOA_SPACE_ID`, `METAMOA_KEY` | 메타모아에 접속자 수 보내기 (아래 참고) |
| `METAMOA_VERIFY` | 메타모아 소유자 확인 코드. 넣으면 확인 메타 태그와 확인 파일이 자동으로 생김 |
| `METAMOA_WEBHOOK_SECRET` | 메타모아 알림 서명 확인용 비밀값 (있을 때만) |
| `PORT` | 서버 포트 (기본 3000) |

## 통계 보기

`https://내주소/stats?key=ADMIN_KEY값`

날짜별로 방문 수, 평균 머문 시간(분), 평균 앉아 있던 시간(분), 머문 시간 분포, 최대 동시 접속, 손 흔들기·띄운 병·받은 병·빈 병·신고 수가 나옵니다.
숫자만 모읍니다. 누가 누구인지, IP 주소는 저장하지 않습니다. 5초 안에 나간 연결(새로고침 등)은 세지 않습니다.
새 장치를 넣을 때마다 이 숫자가 어떻게 바뀌는지 보면 됩니다.

## 유리병 관리

- 목록: `https://내주소/admin/bottles?key=ADMIN_KEY값`
- 숨기기: `https://내주소/admin/hide?key=ADMIN_KEY값&id=번호` (다시 보이기는 `/admin/show`)
- 자동으로 막는 것: 주소·계정, 전화번호 같은 숫자, `server.js` 의 `BANNED` 목록에 있는 말, 80자 넘는 글. 한 사람(같은 연결 주소)은 10분에 한 병만 띄울 수 있습니다.
- 서로 다른 사람 셋이 신고하면 그 병은 더 떠다니지 않습니다.
- 내가 띄운 병은 나에게 오지 않고, 같은 병을 한 번 접속 중에 두 번 받지 않습니다. 바다에 병이 없으면 "빈 병"이 옵니다.
- 금칙어 목록은 아주 기본적인 것만 넣었습니다. 운영하면서 `BANNED` 에 더해 주세요.

## 목포 물때 자료

- 2026년 11월 ~ 2027년 1월은 국립해양조사원 조석예보(목포) 고조·저조 표를 그대로 씁니다(바다타임 게재본에서 옮김).
- 그 뒤로는 같은 표로 맞춘 조석 모형으로 어림하고, 화면에 "(어림)"이라고 붙습니다.
  표 두 달치로 맞춘 모형을 셋째 달에 견줘 보니 만조·간조 시각은 평균 6분, 높이는 평균 30cm쯤 어긋났습니다. 몇 달이 더 지나면 차이가 커집니다.
- 정확도를 유지하려면 석 달쯤마다 새 물때표를 넣어 주세요. `index.html` 의 `TIDE_EXT` 를 새 표로 바꾸면 됩니다.
  나중에 공공데이터포털에서 국립해양조사원 조석예보 API 키를 받으면 서버가 매일 자동으로 받아 오게 바꿀 수 있습니다.
- 물때 자료는 공공저작물이라 출처를 밝히고 씁니다(화면 왼쪽 아래에 표시).

## 인터넷에 올리기

메타모아에 등록하려면 `https://` 로 시작하는 주소가 필요합니다.
이 서버는 접속을 계속 붙잡고 있어야 해서(웹소켓), 정적 파일만 올리는 곳(GitHub Pages 등)에서는 손 흔들기·유리병이 되지 않습니다.
Node.js 서버를 그대로 돌려 주는 곳이면 어디든 됩니다. 예:

- **Render** — 이 폴더를 GitHub 저장소로 올린 뒤 Render에서 저장소를 연결하면 `render.yaml` 을 읽어 자동으로 설정됩니다.
- **Fly.io / Railway / 기타** — `Dockerfile` 로 그대로 배포됩니다.

**병과 통계를 잃지 않으려면 저장 공간을 붙이세요.** 대부분의 무료 요금제는 다시 배포하거나 서버가 다시 켜질 때 파일이 지워집니다.
배포 서비스에서 디스크(볼륨)를 붙이고 `DATA_DIR` 을 그 폴더로 정하면 유지됩니다.

요금제와 무료 범위는 자주 바뀌니 올리기 전에 각 서비스에서 확인하세요.
무료 요금제는 한동안 접속이 없으면 서버가 잠들어 첫 접속이 느릴 수 있습니다.
서버는 한 대로 돌려야 합니다. 여러 대로 늘리면 서로 다른 서버에 붙은 사람끼리는 보이지 않습니다.

## 메타모아에 등록하기

1. <https://metamoa.com/submit> 에서 주소, 공간 이름, 지역을 넣고 신청합니다.
   「접속자 수 API」 칸에는 `https://내주소/live` 를 넣습니다. 지금 바닷가에 있는 사람 수를 숫자 하나로 돌려줍니다
   (`/live?format=json` 은 `{"count": 3}` 모양).
2. 승인되면 메타모아 소유자 화면에서 사이트 확인 코드를 받습니다.
   Render 의 Environment 탭에 `METAMOA_VERIFY` = 받은 코드 를 넣고 저장하면, 서버가 다시 켜지면서
   확인 메타 태그(`metamoa-site-verification`)와 확인 파일(`/metamoa-코드.html`)을 알아서 내보냅니다. 파일을 고칠 필요가 없습니다.
   그다음 메타모아 화면에서 확인 단추를 누릅니다.
3. 확인이 끝나면 `mm_live_` 로 시작하는 공간 키를 받습니다. `METAMOA_SPACE_ID`(공간 번호)와 `METAMOA_KEY`(공간 키)를 환경변수에 넣으면
   서버가 10분에 한 번 지금 접속자 수만 보냅니다. 키는 코드나 채팅에 적지 마세요.
4. (선택) 알림 받기: 메타모아 알림 주소를 `https://내주소/metamoa/webhook` 으로 정하면, 심사 결과 같은 알림이 Render 의 Logs 에
   `[메타모아 알림]` 으로 남습니다. 비밀값을 받았다면 `METAMOA_WEBHOOK_SECRET` 에 넣어 서명을 확인합니다.

접속자 수는 지금 바닷가에 들어와 있고, 최근 3분 안에 신호가 있었고, 자동 프로그램(봇·헤드리스 브라우저)이 아닌 사람만 셉니다.
이름이나 위치 같은 이용자 정보는 보내지 않습니다.

## 바꿔 보고 싶을 때

`public/index.html` 안에서:

- `WAVE_T` — 파도 한 번의 주기 (지금 9.5초)
- `PARASOLS` — 내 색 8가지 (낮엔 파라솔, 밤엔 담요)
- `WORLD_W` — 해변의 가로 길이 (`server.js` 의 같은 값도 함께 바꿉니다)
- `KEYS` — 시간대별 하늘·바다·모래 색
- `FISH` — 노점 카드의 생선 이야기 12종
- `showState` — 미디어아트 상영 시각 (지금 밤 9시부터 10분)
- `scheduleBottle(2, 5)` — 앉은 뒤 첫 병이 오기까지 분

## 알아 둘 점

- 목포대교 조명은 실제 운영 방식(월~목은 계절 색이 은은하게, 금~일은 색이 역동적으로 변함)을 따르지만, 구체적인 색은 임의로 정했습니다. `bridgeHue` 에서 바꿉니다.
- 해변 미디어아트의 실제 영상 내용은 확인하지 못해, 빛 물고기·물결·고래로 상상해 그렸습니다. `drawProjections`, `drawWhale` 에서 바꿉니다.
- 여객선 시간표는 실제 운항표가 아니라 "매 정각"으로 정한 것입니다.
- 채팅은 일부러 넣지 않았습니다. 이름(10자까지)만 다른 사람에게 보이고, 유리병 글은 누가 썼는지 드러나지 않습니다.
  이름에는 금칙어 처리가 없으니, 공개 운영 중 문제가 생기면 이름 표시를 끄거나 걸러 내는 처리를 더하세요.
- 한 바닷가에 500명까지 들어옵니다 (`server.js` 의 `MAX_PEOPLE`).
